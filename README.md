# Hotel PDF Report Generator

A Python script that reads your hotel's monthly data from Excel and generates a formatted PDF report automatically — ready to send to management or investors.

## The problem it solves

Hotel managers spend time every month manually creating performance reports. This script generates a professional PDF in seconds.

## How to use it

1. Fill in your data in `datos_hotel2.xlsx`
2. Double-click `ejecutar.bat`
3. Your report is ready in `reporte_mensual.pdf`

No coding needed on your end.

## What the report includes

- Monthly table with Revenue, Rooms Sold, Occupancy, ADR and RevPAR
- Summary with averages and best performing month

## Setup

Requires Python 3, pandas and reportlab:

pip install pandas openpyxl reportlab
